I am Javier Nogueira, a senior software engineer with [about 30 years of experience](https://www.linkedin.com/in/jntech/) in production software. My recent work is backend systems and AI features that cite their sources.

Recent projects include a cited retrieval-augmented generation (RAG) service over BCRA foreign-exchange regulation, a spec-first security CLI published on PyPI, a [curated registry of coding-agent skills](/Curated-Coding-Agent-Skills/), single-flight lazy caches in [Java](/Java-Simple-Lazy-Cache/) and [C#](/Net-Simple-Lazy-Cache/), an [order saga](/MassTransit-Order-Saga/) on Kafka and Cosmos DB, [in-process throttling](/ASP-NET-Throttling-Middleware/) for ASP.NET Core, and a [comparison of coding agents](/Model-Tests/) on a single TypeScript task. Earlier posts cover machine learning, simulation, and data analysis, including a [published paper on Argentine economic policy](/Argentine-monetary-and-fiscal-policies-analyzed/).

I work remotely or in a hybrid arrangement from La Plata, Buenos Aires.

## How I work

I work specification-first: the specification, then the tests, then the code, using GitHub Spec Kit and [OpenSpec](https://github.com/Fission-AI/OpenSpec). The [Spec Kit write-up](/Spec-Driven-Development-with-Spec-Kit/) walks through the whole loop on a real CLI. A system that answers questions must show where each answer came from, or say that it does not know. [BCRA Mini-RAG](/BCRA-Mini-RAG/) is built on that rule. The Java and C# libraries ship with coverage and mutation testing: JaCoCo and PIT in Java, Coverlet and Stryker.NET in C#.
