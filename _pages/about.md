I am Javier Nogueira, a senior software engineer with about 30 years of experience in production software. My recent work centers on backend systems and on AI features that must cite their sources or decline to answer.

This portfolio presents a selection of systems I have built and can demonstrate: a cited retrieval-augmented generation (RAG) service over BCRA foreign-exchange regulation, a spec-first security CLI published on PyPI, a curated registry of coding-agent skills, single-flight lazy caches in [Java](/Java-Simple-Lazy-Cache/) and [C#](/Net-Simple-Lazy-Cache/), an [order saga](/MassTransit-Order-Saga/) on Kafka and Cosmos DB, [in-process throttling](/ASP-NET-Throttling-Middleware/) for ASP.NET Core, and a [comparison of coding agents](/Model-Tests/) on a single TypeScript task. Earlier posts document learning projects in machine learning, simulation, and data analysis. They remain available for reference but are not the focus of this site.

I work remotely or in a hybrid arrangement from La Plata, Buenos Aires.

## How I work

I develop specification-first: the specification comes first, then the tests, then the code, using GitHub Spec Kit and [OpenSpec](https://github.com/Fission-AI/OpenSpec). The [Spec Kit write-up](/Spec-Driven-Development-with-Spec-Kit/) walks through the complete loop on a real CLI. A system that answers questions must show where each answer came from, or state that it does not know; this is the principle behind [BCRA Mini-RAG](/BCRA-Mini-RAG/). More generally, I favor small services with clear boundaries, predictable deployments, and documentation that lets a new reader run the project unaided.
